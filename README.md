# IOL Lifestyle Recommender

A free, open-source tool for cataract counsellors to score and print personalized IOL options based on patient lifestyle and clinical baseline.

**Live:** https://iol.ratansystems.in/

## Features
- Lifestyle-weighted scoring across five axes
- Toric auto-filter based on astigmatism grade
- Pathology-aware safety filtering
- Trilingual: English, Assamese, Bengali
- Print-ready A4 handout

## Disclaimer
Educational and counselling aid only. Not a substitute for independent ophthalmic biometry, surgical planning, or professional medical judgment.
